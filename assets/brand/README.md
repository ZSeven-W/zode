# Zode desktop brand assets

The canonical repository artwork lives one directory above this folder:

- `../logo.png`: dark Zode artwork.
- `../logo-light.png`: light Zode artwork.

The files in this directory are packaging derivatives of `../logo.png`:

- `zode-logo.png`: byte-identical compatibility copy.
- `zode-512.png`: 512 px Linux and extension source.
- `zode.icns`: macOS application-bundle icon with 16–1024 px representations.
- `zode.ico`: 256 px Windows executable and installer icon.

Do not introduce a second hand-authored mark here. Regenerate these files from
the canonical Zode PNGs, never from Codex/OpenAI resources.
